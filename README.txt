MY GARDEN — ЛОКАЛЬНЫЙ ПРОЕКТ

Нужно: Python 3.11+ и Flask.

Запуск на Windows:
1. Откройте папку MyGarden в PyCharm.
2. В Terminal выполните: python -m venv .venv
3. Активируйте: .\.venv\Scripts\Activate.ps1
4. Установите зависимости: pip install -r requirements.txt
5. Запустите: python main.py
6. Откройте http://127.0.0.1:5000

Страницы: /, /about, /login, /register, /profile.

ВАЖНО: формы входа и регистрации пока демонстрационные. Авторизация и сохранение
данных не реализованы. SECRET_KEY предназначен только для локальной разработки.
